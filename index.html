Política de Privacidad — Control de Ventas

Última actualización: 16 de agosto de 2026

Control de Ventas es una aplicación de gestión personal de ventas, inventario y pagos, diseñada para uso individual y local.

1. Datos que maneja la aplicación

La aplicación almacena exclusivamente la información que tú mismo introduces: clientes, ventas, pagos e inventario. No recolecta datos de terceros, no usa cookies de seguimiento ni herramientas de analítica.

2. Uso de tu cuenta de Google

Para respaldar la base de datos de la aplicación, esta solicita acceso al almacenamiento de Google Drive de tu propia cuenta. Ese acceso se utiliza únicamente para:

  • Subir (escribir) el archivo de respaldo de tu base de datos.
  • Leer y actualizar el mismo archivo de respaldo en sincronizaciones posteriores.

La aplicación no accede a otros archivos de tu Drive, no comparte tus datos con terceros y no los utiliza para publicidad.

3. Almacenamiento y seguridad

La base de datos se guarda localmente en tu equipo. El respaldo se sube a la carpeta de Google Drive que tú autorizas. Solo tú (o alguien con acceso a tu cuenta de Google) puede ver ese contenido.

4. Contacto

Para consultas sobre esta política, contacta al desarrollador a través de la cuenta de Google asociada a la aplicación.
